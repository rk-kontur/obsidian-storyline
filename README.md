# Archive: release files of 1.12.0-km.1 to 1.12.0-km.13

These GitHub releases were deleted because BRAT (which includes pre-releases
when it looks for updates) ranked them above the current `1.11.8-km.*` line.
The git tags `1.12.0-km.*` still exist; this branch keeps the release assets
(`main.js`, `manifest.json`, `styles.css`, source zip and patches) exactly as
they were attached to each release. The release texts are archived in the
owner's vault.

This branch is an archive only. Do not merge it.
